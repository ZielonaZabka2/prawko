# Anti-slop

Slop = treść lub design, który mógłby należeć do **każdej** firmy. Test: zakryj logo – czy da się odgadnąć, czyja to strona? Jeśli nie, to slop.

## 1. Sygnały w tekście (PL)

| Sygnał | Przykład | Naprawa |
|---|---|---|
| Konstrukcja „nie X, tylko Y” / „nie tylko… ale” | „Uczymy jazdy, nie tylko zdawania” | Powiedz wprost, co robisz, z faktem |
| Aforyzmy i bon-moty | „Stres to najgorszy nauczyciel” | Usuń albo zamień na konkret |
| Trójki przymiotników | „szybko, skutecznie i w przyjaznej atmosferze” | Jeden przymiotnik + dowód |
| „Spokojnie”, „bez stresu”, „z pasją”, „kompleksowo” | | Liczba, nazwa, cena, termin |
| Puste wzmacniacze | „profesjonalny”, „najwyższa jakość”, „wyjątkowy” | Usuń; pokaż dowód |
| Nadmiar myślników (–) w roli przecinka/dwukropka | 3+ na akapit | Kropka albo dwukropek |
| Pytania retoryczne na start | „Marzysz o prawie jazdy?” | Zacznij od odpowiedzi (BLUF) |
| Fałszywa bliskość, emoji, „🚀🔥” | | Ton rzeczowy, bez emoji w UI |
| Jednolity rytm zdań | same zdania 12–15 słów | Mieszaj krótkie i dłuższe |
| Wymyślone liczby i opinie | „98% zdawalności”, „tysiące kursantów” | **Nigdy** – tylko dane klienta |

## 2. Sygnały w designie

- Fioletowo-niebieskie gradienty, glassmorphism, rozmyte „bloby” w tle.
- Font Inter/Poppins wszędzie, wszystko wyśrodkowane.
- Każda sekcja z identycznym rytmem: **mała etykieta z kreską („eyebrow”) → H2 → akapit → siatka 3 kart z ikonką**.
- Ikony w kolorowych kółkach/kwadratach przy każdym punkcie.
- Stockowe zdjęcia uśmiechniętych ludzi, ilustracje 3D, „abstrakcyjne kształty”.
- Hero „Odkryj / Zmień / Twoja podróż”, dwa przyciski, mockup obok.
- Karty z identycznym cieniem i zaokrągleniem w całym serwisie, zero zmiany rytmu.
- Efekty-wydmuszki: glitch, magnetyczne przyciski, liczniki wszystkiego.

## 3. Co robi stronę nie-slopową

- **Konkret klienta:** adres, ulica, nazwisko, cena, liczba godzin, marka auta, prawdziwe zdjęcia.
- **Motyw z branży klienta** zamiast ogólnego „tech” (np. dla szkoły jazdy: pas ruchu, znak, tablica „L”, trasa).
- **Zmienny rytm sekcji:** tabela, lista numerowana, duże zdjęcie, FAQ – każda sekcja inna forma.
- **Głos klienta:** zdania, które klient mówi przez telefon, a nie hasła reklamowe.
- **Uczciwość:** to, czego nie wiemy, oznaczamy jako „do potwierdzenia”, a nie zgadujemy.

## 4. Procedura audytu

1. Zbierz tekst ze wszystkich stron (bez skryptów i nawigacji).
2. Policz sygnały z tabeli 1 (wyrażenia regularne + czytanie). Podaj liczby i 3–5 cytatów na sygnał.
3. Przejdź design wg listy 2 (zrzuty ekranu komputer + telefon).
4. Oceń każdy sygnał: 🔴 rzuca się w oczy / 🟡 pojedyncze wystąpienia / 🟢 OK.
5. Napraw: przepisz zdania na konkret, usuń powtórzenia, zróżnicuj sekcje. Nie dodawaj faktów, których nie potwierdził klient.
6. Wynik: tabela przed/po + lista rzeczy do potwierdzenia z klientem.
